Git hooks - это скрипты внутри .git/hooks/, которые Git выполняет при определенных действиях (commit, checkout и т.д). Заразив один из хуков (например, post-checkout), можно сделать чтобы при переключении веток запускалась наша нагрузка.
Разработчик часто использует git. Хук сработает локально, незаметно и с правами текущего пользователя (или root, если репозиторий системный). Обнаружить вручную сложно, если не просматривать все хуки во всех проектах.

PAM (Pluggable Authentication Modules) отвечает за аутентификацию в Linux. Модуль pam_exec.so позволяет выполнить внешнюю программу при различных событиях аутентификации. Добавляется вызов скрипта в стек auth для sshd (или login). Скрипт получает через stdin пароль пользователя (при expose_authtok) и может сохранить его, а также выполнить полезную нагрузку.
Это дает выполнение кода при каждом входе в систему (локальном или удаленном) с правами входящего пользователя и позволяет перехватывать учетные данные.

Sed – потоковый редактор текста. Мы ищем @include common-auth и подставляем к процессу по умолчанию при аутентификации свой скрипт.
Теперь при каждом входе по SSH PAM сначала вызовет скрипт, передаст ему пароль через stdin, и потом перейдет к обычной проверке пароля.

Вывод:
Ошибка в конфигурации PAM может полностью заблокировать вход в систему, в данном случае используется аргумент  ( auth optional ), что по идее позволит продолжить вход даже в случае ошибки скрипта ( штатная работа не будет нарушена ) 
Скрытность:
•	/var/log/auth.log зафиксирует вызов pam_exec
•	Изменение в /etc/pam.d/sshd легко заметить при аудите
•	Файл /usr/local/bin/pam.sh также может быть обнаружен

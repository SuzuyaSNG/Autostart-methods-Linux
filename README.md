# Autostart-methods-Linux

Цель: Методы автозапуска в ОС семейства Linux
Описание задач: изучить методы автоматического запуска команд в Linux, описать стенды таких методов и проанализировать последствия выполненных операций и насколько метод является незаметным для администраторов ИБ.
формирование компетенций для создания скрытых механизмов доступа к скомпрометированной системе, гарантирующих сохранение контроля даже после перезагрузки.
Используемое ПО для выполнения задачи: Oracle VirtualBox, OS 6.8.0-107-generic #107~22.04.1-Ubuntu VM
